Добро пожаловать в Syllogimous!

Syllogimous — тренажёр реляционной интеграции: в каждой задаче нужно связать все посылки в одну картину. Лишних посылок нет — без любой из них ответ не выводится.

Сложность — это число посылок. Оно растёт после верных ответов и падает после ошибок; в настройках его можно задать вручную для каждого типа задач.

Ответов три: «Следует», «Неизвестно», «Противоречит». После ошибки показывается разбор.

Результат в тренажёре — не IQ. Тренировка улучшает решение похожих задач; рост общего интеллекта не обещается — для проверки переноса есть раздел «Контроль переноса».
